# v0 — Ink Lab

This is the tested, standalone stylus-input spike. Strokes are stored as vector point sequences in memory and redrawn when zooming. It does not save notes.

With Node.js 22.12+ installed, run `npm install` and `npm start` from this folder. Test pressure, tilt, palm rejection, eraser button, pointer event streams, and the timing display on a real stylus device.
